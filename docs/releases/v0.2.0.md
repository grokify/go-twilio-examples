# Release Notes v0.2.0

**Release Date:** October 20, 2026 (planned)

## Overview

This release adds a MkDocs documentation site with a guide for each example, removes the hardcoded host from the Media Streams example, and brings dependencies and tooling up to date.

## Breaking Changes

| Change | Action |
|--------|--------|
| `media-streams` requires `BASE_URL_WSS` and exits at startup without it | Set `BASE_URL_WSS=wss://<your-host>.ngrok.io` before running |
| Unused `msg` field removed from `GatherEvent` | Remove any references to it |
| Minimum Go version is 1.26 | Upgrade your toolchain |

## Features

### Documentation site

`mkdocs.yml` and `docs/` provide a [Material for MkDocs](https://squidfunk.github.io/mkdocs-material/) site with guides for [Appointment Reminders](../guides/appointment-reminders.md), [Outbound Call](../guides/outbound-call.md) and [Media Streams](../guides/media-streams.md). The per-example READMEs are now short pointers to these guides, and their stale paths were corrected.

### Configurable Media Streams host

The WebSocket base URL is read from `BASE_URL_WSS` and used for both the `<Stream>` URL in the TwiML and the service router, instead of a hardcoded tunnel host.

## Bug Fixes

- appointment-reminders: set `ReadHeaderTimeout` on the HTTP server.

## Other Changes

- `processResponse` no longer takes an unused request parameter.
- CI workflows renamed to the standard `go-ci`, `go-lint` and `go-sast-codeql`; `.golangci.yaml` updated.
