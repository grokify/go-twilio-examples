# Release Notes v0.1.0

**Release Date:** March 21, 2021

## Overview

This release adds the Twilio Media Streams example and consolidates shared code at the repository root.

## Features

### Media Streams example

The `media-streams` example serves TwiML containing `<Start><Stream>` and accepts the resulting WebSocket connection. Inbound audio is decoded and written to file. See the [Media Streams guide](../guides/media-streams.md).

### Stream message types

`StreamMessage` and related types model the JSON events Twilio sends over a Media Streams WebSocket: `connected`, `start`, `media`, `stop` and `mark`.

## Changes

- Logging moved from logrus to zerolog.
- Shared helpers moved to the repository root so the examples import one package.
- GitHub Actions CI added; the cron schedule was later removed.
- Dependencies and license updated.

## Installation

```bash
go get github.com/grokify/go-twilio-examples@v0.1.0
```
