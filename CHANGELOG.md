## [v0.2.0] - 2026-10-20

### Highlights

- MkDocs documentation site with a user guide for each example, replacing the stale per-example READMEs
- `media-streams` no longer hardcodes its public WebSocket host; set `BASE_URL_WSS` instead

### Breaking

- `media-streams` exits at startup unless `BASE_URL_WSS` is set; the previous hardcoded host was removed
- `GatherEvent.msg` field removed

### Added

- MkDocs site (`mkdocs.yml`, `docs/`) with guides for appointment-reminders, outbound-call and media-streams
- Release notes under `docs/releases/`
- `outbound-call/README.md` pointing to its guide

### Changed

- `media-streams` reads its WebSocket base URL from the required `BASE_URL_WSS` environment variable and uses it for both the `<Stream>` URL and the service router
- Root and per-example READMEs rewritten to match the current layout, with corrected paths and run instructions
- `processResponse` in appointment-reminders controllers no longer takes an unused request parameter
- Standard CI workflow names (`go-ci`, `go-lint`, `go-sast-codeql`) and updated `.golangci.yaml`
- Minimum Go version is now 1.26

### Removed

- Unused `msg` field from `GatherEvent`

### Fixed

- appointment-reminders: set `ReadHeaderTimeout` on the HTTP server ([`1089560`](https://github.com/grokify/go-twilio-examples/commit/1089560))

- _5 dependency updates_
